Auto-claim expired positions
When checked, queries the claimable amount every 15 seconds and batch-claims on-chain settled winning positions every 5 minutes (redeemed into the Safe wallet's pUSD balance).
· Calls V2 CtfCollateralAdapter.redeemPositions
· 5-second interval between claims, auto-retries once on failure
· Each claim costs ~$0.01 POL gas, paid by the local private-key wallet
· Skips this round automatically while a strategy is placing an order, to avoid nonce conflicts

📱 How to configure Telegram push
① Create a bot (get a Bot Token)
· Search @BotFather in Telegram and start a chat
· Send /newbot, and follow the prompts to set the bot name
· BotFather returns a Bot Token (looks like 1234:ABCD...); copy and paste it into the input box below
② Get the Chat ID (the account that receives pushes)
· Open the bot you created in Telegram, click "Start" or send /start
· Return to this panel, fill in the Bot Token, then click 🔍 Auto detect; the Chat ID will be filled in automatically
③ Enable push
· Check "Enable" and set the push interval
· Click "Save" to apply
· Click "Test send" to verify the bot can push messages

ⓘ Before use, send /start to the bot in Telegram, then click "Auto detect"
